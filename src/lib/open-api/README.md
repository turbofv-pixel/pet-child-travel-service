# 오픈API 연동 자리표시자

이 디렉터리는 외부 오픈API 클라이언트를 붙일 자리입니다. 아직 실제 연동은 되어있지 않고,
후보로 검토 중인 API만 정리해둔 상태예요.

| 목적 | 후보 API | 비고 |
| --- | --- | --- |
| 관광지 / 펫프렌들리 업소 정보 | 한국관광공사 TourAPI, 지자체 공공데이터포털 (반려동물 동반가능 업소) | 인증키 필요 |
| 지도 / 경로 안내 | 지도 오픈API (Kakao/Naver 지도 등 후보) | 인증키 필요 |
| 날씨 | 기상청 오픈API (단기예보) | 인증키 필요 |

API 키는 절대 커밋하지 말고 `.env.local`에 두세요 (`.env.example` 참고).

## 앞으로 할 일

- [ ] 각 API 응답을 `src/types`의 `Spot` 모델로 매핑하는 어댑터 작성
- [ ] API별 클라이언트 모듈 추가 (예: `tour-api.ts`, `weather-api.ts`, `map-api.ts`)
- [ ] 요청 실패/레이트리밋 처리 공통 유틸
